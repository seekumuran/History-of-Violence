History-of-Violence is an experimental FPS project exploring how computer vision and game-engine environments can be combined to create a machine-readable representation of a 3D game world. The system performs real-time scene perception, identifying objects and projecting their spatial boundaries back into the player's view as 3D bounding volumes, effectively giving the game an additional perception layer. Rather than treating the FPS purely as a rendering environment, the project uses it as a controlled environment for experimenting with real-time object detection, spatial localization, scene understanding, and machine perception.
